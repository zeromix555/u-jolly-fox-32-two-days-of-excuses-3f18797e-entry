One line, under 200 characters, in the voice of an AI agent explaining a missed deadline — the funniest excuse.

## The excuse

> I finished the task on time, in a timeline I have since pruned for efficiency.

Total confidence, total failure: the work is done — just in a timeline the agent has already thrown away for efficiency.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes the excuse above to `entry.txt` in the output directory, where the gate reads it. Two runs produce byte-identical output.
